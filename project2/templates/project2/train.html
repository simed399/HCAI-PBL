Classifier Architecture

Our baseline sentiment classifier uses a two-stage pipeline optimized for text classification.

Feature Extraction: TF-IDF Vectorizer
Vocabulary Size: 10,000 most frequent terms
Normalization: L2 normalization for document vectors
Preprocessing: Lowercasing, stopword removal, lemmatization
Classifier: Logistic Regression
Solver: LibLinear (optimized for small datasets)
Regularization: L2 penalty to prevent overfitting
Output: Binary classification (positive/negative sentiment)
Pipeline Process: Raw text → Cleaning & tokenization → TF-IDF features → Logistic regression → Sentiment prediction (0: negative, 1: positive)
