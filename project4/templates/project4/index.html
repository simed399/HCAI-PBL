Influence of Future Predictions over Active Learning of Users' Tastes for Recommender Systems

Goal: Develop and test an interactive method where a new user enters their tastes. The twist is that unlike standard active learning, the system also shows the user how their answer will affect the recommendations — so the user may choose answers more strategically.

Project Overview

About the Recommendation System

This project uses matrix factorization on the MovieLens dataset to create personalized movie recommendations. The system learns your preferences through an active learning process that strategically selects which movies to ask you about.

The Cold Start Problem

When a new user registers, the system knows nothing about them. Our approach addresses this by:

  • Asking you to rate several movies selected by an intelligent algorithm
  • Showing you how your answers will affect the recommendations (the key innovation!)
  • Allowing you to make more strategic rating choices
